Cyber Rakshak 

Is an AI-powered cybersecurity application developed to protect users from increasing digital frauds such as scam calls, phishing messages, and fraudulent emails. With the rapid growth of online transactions and communication, users are becoming more vulnerable to cyber threats. This project aims to provide a smart and user-friendly solution to tackle these issues in real time.
The core functionality of the system is to automatically detect and flag suspicious activities. It analyzes incoming calls, SMS, and emails using AI-based APIs to identify patterns commonly associated with scams. When a potential threat is detected, the user is instantly alerted, helping them avoid falling victim to fraud.
One of the key features of Cyber Rakshak is its multi-layered protection system. It includes a “Trust Circle,” which allows users to connect with family members and share alerts, ensuring collective safety. Additionally, it maintains shared blocked lists so that once a scam is identified, it can be prevented for other users as well.
The application also provides an integrated reporting mechanism, enabling users to report fraud incidents directly to relevant authorities. It can generate necessary evidence, making the reporting process faster and more effective.
From a technical perspective, the system is built using Kivy and KivyMD for the frontend, ensuring a simple and interactive user interface. The backend uses APIs like Google Gemini and Sightengine for intelligent analysis, along with SQLite for lightweight data storage.
Overall, Cyber Rakshak focuses on combining AI technology with community-driven protection to create a secure digital environment. It not only helps in detecting scams but also spreads awareness and builds trust among users while using digital platforms.
